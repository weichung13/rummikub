# 房間可選三分鐘沙漏

- 狀態：已實作未發布。
- 規格：ROOM-10／UI-11。
- 目的：房主可選限時遊玩，以動畫與數字讓同桌玩家掌握剩餘時間。
- 使用者確認：期限到自動摸一張並換人，牌堆空則略過，未提交草稿撤銷。

## 設計與範圍

建立時選擇、預設關閉，單回合固定 180 秒。伺服器保存期限並判定到期，前端只顯示。抽取 TurnClock 與 TurnHourglass，各自管理計時生命週期與呈現。沿用既有摸牌與回合推進；重連不重設，重開新局沿用房間設定。

不包含任意秒數、暫停、局中修改設定、音效或推播。新版協定需前後端一起部署；未帶設定的建立請求維持不限時。

## 驗收

- 開關預設關閉；開啟的兩個玩家看到同回合倒數。
- 180 秒才到期且只處理一次；新回合重新三分鐘、取消舊計時；截止後請求不得繼續出牌。
- 摸牌到牌堆空後依規則略過至平手；結束期限清空，再來一場重新開始。
- 重連期限不變，320／375px 與桌面不溢出。

## 驗證紀錄

十項自動化測試通過，含 Node 虛擬時鐘與真實 Socket 的到期／耗盡／重開流程。雙人獨立瀏覽器工作階段驗證建立開關、沙漏顯示及三種版面；沒有使用瀏覽器實等全部 180 秒作為到期測試。

納入 2026-10-05 更新批次；部署狀態尚未確認。網路延遲可能使顯示時間稍有差異，最終以伺服器期限為準。

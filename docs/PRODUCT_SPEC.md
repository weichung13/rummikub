# Rumi Club 產品規格

此文件描述工作目錄目前已實作的產品行為，包含未發布修改；發布狀態見 [變更紀錄](../CHANGELOG.md)。更新日期：2026-10-05。

## 定位與範圍

手機優先的 2–6 人線上拉密。玩家以暱稱與房間代碼同桌遊玩，不需帳號。介面採深綠牌桌、米白牌面與亮綠重點色。以點選排牌為主，沒有拖曳與手牌排序切換。

## 房間流程（ROOM）

- ROOM-01：首頁先選「加入朋友的房間」或「我要開新房間」，再填寫暱稱；各表單只有一個送出動作，建立房間需按「確認建立房間」。暱稱最多 18 字元。
- ROOM-02：加入需要 5 碼房間代碼；邀請網址 `/?room=ABCDE` 直接開啟加入表單並帶入代碼。已有有效保存座位時，連線仍會優先嘗試恢復原座位。
- ROOM-03：建立者是房主。至少 2 人才能開始，最多 6 人；牌局進行中不接受新玩家，只接受原玩家重連；結束後可加入新玩家參與下一局。
- ROOM-04：房主按開始後，由伺服器隨機選出先手，不固定由房主開始；之後依座位順序輪流。
- ROOM-05：分享按鈕複製邀請連結，失敗時提示手動分享代碼。
- ROOM-06：等待中主動離開會移除座位，房主離開優先交接給在線玩家，否則交接給剩餘第一位玩家；最後一人離開會刪除房間。
- ROOM-07：遊戲中離開先顯示確認視窗；確認後結束本局，不判定勝負。其他玩家可留在原房間再來一場，或返回大廳。遊戲已結束時可直接離開。
- ROOM-08：收到伺服器離開回覆後，前端清除保存座位與本地牌局狀態，返回入口，保留當前暱稱方便再次入座。

## 遊戲規則（GAME）

| 項目 | 現行規則 |
| --- | --- |
| 2–4 人 | 106 張：四色 1–13 各兩套，2 張鬼牌 |
| 5–6 人 | 160 張：四色 1–13 各三套，4 張鬼牌 |
| 起手 | 每人 14 張 |
| 順子 | 同色連號，至少 3 張，範圍 1–13，不可首尾循環 |
| 同數字組 | 3–4 張相同數字，實體數字牌顏色不可重複 |
| 鬼牌 | 可填補缺牌，純鬼牌牌組不合法；桌面鬼牌不得在提交時消失 |
| 首次出牌 | 自己的新牌組合計至少 30 點；原有桌面牌組須保持原組，不得接牌或重組 |
| 首次出牌之後 | 可重組桌面，但原有每張牌都必須保留，且每組均合法 |
| 每次提交 | 至少使用一張自己的手牌；不可重複使用同一張實體牌 |
| 摸牌 | 摸一張並結束回合；系統不強制搜尋玩家是否存在可出牌方案 |
| 勝負 | 出完手牌者獲勝；不做剩牌計分 |
| 牌堆用完 | 全體連續一輪略過則平手；出牌成功會重設連續略過次數 |

GAME-01：鬼牌點數採所代替的牌值。順子有多個合法範圍時，使用最高總點數範圍；同數字組按該數字計算。這是本專案目前實作，不宣稱涵蓋所有版本的官方規則。

## 排牌與回合提醒（UI）

- UI-01：手牌固定依紅、藍、黃、黑、鬼牌分組，各組按數字排列。牌面不在數字下重複顯示顏色文字；保留區域分類標籤與無障礙牌名。
- UI-02：選至少 3 張可組成新組；選牌後可點可操作牌組旁的「加入選取牌」。未開局者只能修改自己的新牌組。
- UI-03：草稿可暫時不合法；各牌組顯示錯誤提示。支援取消選取、復原一步與全部重設。
- UI-04：首次點數只計入有效的新牌組；桌面合法、用到自己的新牌且達開局門檻才可提交。伺服器仍執行完整驗證。
- UI-05：有排列操作紀錄時，摸牌需先確認撤銷；取消確認會保留排列。
- UI-06：手機固定底部操作列，底部留白跟隨操作列高度；長牌組可橫向捲動。
- UI-07：等待其他玩家與首次出牌點數統一顯示於底部操作列，不在手牌區重複。
- UI-08：本回合新放的牌以邊框區分；已提交的最近變動牌短暫高亮，不持續閃爍。
- UI-09：輪到自己時出現「輪到你出牌了！」橫幅，3 秒後收起，也可手動關閉。底部持續高亮「你的回合」，網頁標題改成「輪到你了！｜Rumi Club」。同一回合切回分頁再次顯示橫幅；回合結束或離開即恢復原標題。
- UI-10：顯示連線、重連與處理中狀態。離線或請求等待時停用相關操作；目前沒有音效、系統推播或震動提醒。

## 身分、同步與保存（SYNC）

- SYNC-01：伺服器產生公開玩家 ID 與獨立私密重連 token，token 不向其他玩家廣播。每位玩家只收到自己的手牌及其他人的張數。
- SYNC-02：每次操作確認 socket 仍屬於該玩家；另一分頁接手同一座位時，中止舊連線。
- SYNC-03：牌局 `revision` 在開始、成功出牌、摸牌／略過、進行中主動離開導致結束時遞增。單純連線狀態或等待室人數更新不重設排牌草稿。
- SYNC-04：網路重連且牌局未推進時保留草稿；整頁重新整理不保存未提交草稿。座位憑證保存在瀏覽器 localStorage。
- SYNC-05：房間只存伺服器記憶體，重啟會清空。斷線不是主動離開，保留原座位供重連。

## 已知限制與未實作項目

- 不限時房間尚無斷線逾時、自動代摸／跳過，玩家斷線不回來仍可能卡住牌局；沙漏房間即使玩家離線也會按回合期限自動換人。尚無房主踢人。
- 沒有閒置房間定時清理；只有最後一人主動離開時刪除房間。
- 沒有跨服務實例房間同步、資料庫恢復、觀戰、計分或帳號功能。
- 拖曳操作留待後續；排序切換目前明確不納入需求。
- 3 秒提醒、離開與入口流程的發布與驗證狀態，以變更紀錄及該次開發報告為準。

## 同房再來一場（ROOM-09）

牌局結束（獲勝、平手或有人主動離開）後，房主可按「再來一場」。至少 2 位玩家且所有座位皆在線才可開始；其他玩家顯示等待房主。保留房號、玩家身分與座位順序，依目前人數重建牌堆、洗牌、每人重新發 14 張，隨機選先手；清空桌面、首次出牌資格、勝者、連續略過與最近變動標記，牌局版本遞增以重設前端草稿。進行中不能重複開始。結束後可分享原邀請連結補足玩家。

## 三分鐘沙漏（ROOM-10／UI-11）

- 房主建立房間時可勾選「啟用 3 分鐘沙漏」，預設關閉；設定建立後固定，再來一場沿用原設定。舊用戶端未傳設定時視為關閉。
- 等待室顯示是否啟用。牌局開始與每次換人時，由伺服器設定完整 180 秒期限，所有玩家看到同一回合的沙漏與數字倒數。
- 沙漏上方沙量隨剩餘時間降低，下方逐步累積；最後 30 秒以醒目色提示。減少動態效果設定下停止流沙裝飾動畫，仍顯示剩餘時間。
- 時間到自動摸一張並換人；牌堆空則略過，連續全員略過仍依原規則平手。未提交排列與復原紀錄隨回合版本更新撤銷。
- 合法出牌或手動摸牌立即開始下一位的完整三分鐘；不合法出牌不重設期限。斷線、重新整理與重新加入都不延長回合。
- 截止後抵達伺服器的出牌不接受；即使計時回呼延後，操作入口仍檢查期限，避免同回合重複摸牌。網路延遲可能使畫面倒數略有差異，判定以伺服器為準。
- 獲勝、平手、主動離開結束本局、刪除房間時取消計時。未啟用者維持不限時。
